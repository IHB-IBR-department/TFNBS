# ABIDE I Multi-Site Validation Suite

This directory contains the production-ready validation suite for `conninfpy` using the ABIDE I cohort. It demonstrates multi-site harmonization (Strategy D), topological stability, and biological discovery across seven core figures.

## 1. Data Preparation

All analysis scripts depend on the prepared dataset generated by:
- **`prepare_data.py`**: Performs QC (ts_length >= 100, mean FD <= 0.5mm), regresses out global mean from ROI timeseries, and aggregates a balanced subset of 15 sites into `results/abide_prepared.npz`.

## 2. Core Execution Scripts

The following scripts generate the statistical results (CSV/NPZ) required for plotting:

| Script | Purpose | Output |
|---|---|---|
| `run_age_strategy_d.py` | Positive control sweep for Age and Motion effects using ComBat Strategy D. | `results/age_development/age_strategy_d_edges.csv` |
| `run_age_method_comparison.py`| Pairwise agreement analysis across statistical methods (NBS, TFNBS, etc). | `results/age_development/methods/*.npz` |
| `run_eh_sensitivity.py` | Grid sweep of TFNBS (E, H) parameters to prove topological stability. | `results/age_development/sensitivity/eh/*.csv` |
| `run_dx_site_glm.py` | Canonical Strategy D diagnosis contrast (ASD vs HC). | `results/diagnosis/dx_strategy_d_edges.csv` |
| `run_naive_baseline.py` | Naive diagnosis contrast (No site dummies, no ComBat). | `results/diagnosis/naive/dx_naive_edges.csv` |
| `run_dx_combat_only.py` | ComBat-only diagnosis contrast (No site dummies in GLM). | `results/diagnosis/combat_only/dx_combat_only_edges.csv` |
| `run_dx_strategy_e.py` | Site dummies ONLY diagnosis contrast (No ComBat). | `results/diagnosis/strategy_e/dx_strategy_e_edges.csv` |
| `run_dx_network_variants.py` | Comparison of network-informed methods (NI-TFNBS, FBC-TFNBS, cNBS). | `results/diagnosis/dx_*_edges.csv` |

## 3. Publication Figures

**Output Directory:** `results/plots/`

The primary plotting script is **`plot_paper_figures.py`**, which aggregates the entire story. Standalone scripts for complex multi-panel figures are also provided.

| Plot # | Filename | Script | Claim / Description |
|---|---|---|---|
| **1** | `plot1_combat_site_variance.png` | `plot_paper_figures.py` | **Site Neutralization**: Shows how Strategy D crushes site variance to null levels. |
| **2** | `plot2_dx_effect_size_distribution.png`| `plot_paper_figures.py` | **Effect Sizes**: Characterizes the small, real univariate effects in ABIDE ASD discovery. |
| **3** | `plot3_network_block_mass.png` | `plot_paper_figures.py` | **Systems Neuroscience**: Visualizes network-level integration/segregation patterns. |
| **4** | `plot4_dual.png` | `plot_method_sensitivity.py` | **Method Sensitivity**: Demonstrates stability (Jaccard) and convergence (Spearman) of TFNBS. |
| **5** | `plot5_tfnbs_grid_sensitivity.png` | `run_eh_sensitivity.py` | **Parameter Multiverse**: Proves TFNBS is insensitive to specific (E, H) choices. |
| **6** | `plot6_diagnosis_methodology.png` | `plot_diagnosis_quadrant.py` | **Site Control Evolution**: Contrasts Naive vs Site-Aware tiers to prove Strategy D necessity. |
| **7** | `plot7_diagnosis_hierarchy.png` | `plot_diagnosis_hierarchy.py` | **System-Level Convergence**: Shows how network-informed priors prune topological leakage. |

## 4. Quick Start

To regenerate the entire validation story from scratch:
```bash
# Activate environment
conda activate conninfpy

# 1. Prepare data
python prepare_data.py

# 2. Run statistical sweeps
python run_age_strategy_d.py
python run_age_method_comparison.py
python run_eh_sensitivity.py
python run_dx_site_glm.py
python run_naive_baseline.py
python run_dx_combat_only.py
python run_dx_strategy_e.py
python run_dx_network_variants.py

# 3. Generate all plots
python plot_paper_figures.py
python plot_method_sensitivity.py
python plot_diagnosis_quadrant.py
python plot_diagnosis_hierarchy.py
```
